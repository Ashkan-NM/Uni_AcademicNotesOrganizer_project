# Academic Notes Organizer

A Django-based system for managing academic notes - Advanced Programming Course Project

## Features
- User registration and login
- Create, edit, and delete courses
- Create, edit, and delete notes (with title, description, and content)
- Tree-structured display of courses and notes (expandable/collapsible)
- Text search in note titles and content
- Containerized with Docker

## Prerequisites
- Python 3.8 or higher
- Docker and Docker Compose (for Docker execution)
